# Use a photo invitation without an internet connection

This free editor creates invitation text, not photos. It does not upload photos, store your note or send an invitation automatically.

1. Extract the ZIP into a folder you choose. Keep its three files: `photo-invitation.html`, `README.md` and `LICENSE`.
2. Open `photo-invitation.html` in a browser. If your file manager shows a text editor, use **Open with** to choose a browser.
3. Choose **Family**, **Couple** or **Small team**. The preview changes to that audience.
4. Choose **Plain text** or **Markdown**.
5. To add an instruction, open **Add an organizer note**. Keep names and contact details out. The limit is 240 characters.
6. Review the invitation and its permission and paid-generation notices.
7. Click **Copy invitation**. If copying is unavailable, select the invitation and copy it yourself.
8. Paste the invitation into your own chat or email. Review the pasted text before you send it yourself.

To keep a text file, click **Download text**. Complete the download in your browser. The text or Markdown includes your optional note.

To make a paper invitation, click **Print invitation**. Choose a printer or Save as PDF in the browser dialog. Complete printing or saving yourself. The print layout includes the selected card, your optional note, readable online links and the permission, AI and purchase notices. Review the paper or PDF before sharing it. Without JavaScript, the browser's Print command prints the default family card.

To reopen the selected audience and format online, click **Copy link to this card**. The link opens the public editor, not your local file. It excludes your optional note. Send the complete invitation text if the recipient needs your instruction.

Editing, text preparation and the print layout work without a connection. Scene planning, the app guide and other external links need internet access. This file does not install an app, generate a photo, send portraits or import a prompt into the app.

Changing the audience or reloading the file clears the note. The editor holds the note only in the current tab. Saving the original HTML file does not save your edited note. Do not send anyone's portrait through this tool.

Taking part is optional. Ask each person which portrait they permit you to use. For a child's photo, ask their parent or guardian first. TogetherLens creates a new AI composition from separate photos of two to five people, not a record of an event everyone attended. Review results before sharing them as AI-generated.

The separate TogetherLens app is free to install. Photo generation uses paid tokens. Premium is optional and auto-renews. Check current prices and terms in the app before buying. The invitation has no event fee.
