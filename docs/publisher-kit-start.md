# Add the downloaded invitation to your page

Use this free HTML block on a family page or small-team handbook. It provides invitation text, not photo generation. You do not need a package manager, account, or JavaScript dependency.

1. Download `togetherlens-html-invitation-kit-2026-10-03.zip` from the [HTML invitation kit release](https://github.com/m0k13/togetherlens-photo-prompt-card/releases/tag/invitation-kit-2026-10-03).
2. Unzip the download. Open `invitation-block.html` in your browser.
3. Open **Open invitation text**. Select the text and check what your readers would send.
4. Open `invitation-block-snippet.html` in a text editor. Copy its contents into the body of your page.
5. If your site disallows inline CSS, move the style rules into your stylesheet. Keep the `.tl-photo-invite` selectors scoped.
6. Preview your page on a phone. Use the keyboard to open the disclosure and select the invitation text.

The preview and snippet work without a network connection. Their links open online pages only when you choose them. Keep the permission, refusal, parent or guardian, AI disclosure, and paid-generation notices. Add personal details in your own chat, not on a public page.

The kit contains these five files:

- `invitation-block.html` is the standalone preview.
- `invitation-block-snippet.html` is the HTML and scoped CSS to copy into your page.
- `add-invitation-block.md` is the integration guide and a matching code block.
- `README.md` contains these setup instructions.
- `LICENSE` contains the MIT reuse terms. Keep its copyright and permission notice with your copy.

The kit collects no photos or contact details. It includes no script, embedded page, analytics, storage, or automatic sending. It creates no image and imports nothing into an app. The separate TogetherLens app is free to install; photo generation uses paid tokens and Premium is optional. Check current prices and terms before buying.

If you want to create the portrait afterward, [read the app-workflow section in the repository README](https://github.com/m0k13/togetherlens-photo-prompt-card#before-anyone-shares-a-portrait). It explains the photo preparation and links to the iOS and Android workflow.

The JavaScript library remains version 0.1.0. Its existing package archives are unchanged, and the library is not published on the npm registry. This ZIP is a separate website-integration kit. You can also [use the live example](https://m0k13.github.io/togetherlens-photo-prompt-card/examples/invitation-block.html) without downloading anything.
